# GPT Image 2 prompt guide

- Best fit: readable Chinese/multilingual copy, structured layouts, multi-element composition, exact local edits, and consistency-sensitive finals.
- Write a compact creative brief with labeled blocks when complexity warrants: `Artifact`, `Scene`, `Subject`, `Composition`, `Text`, `Preserve`, `Constraints`, `Medium`.
- Quote literal copy once and label it verbatim. Put each text element and placement on its own line. Treat named fonts as visual hints; use deterministic layout when exact typography still fails.
- Index every supplied reference and state one role per image. Repeat the complete preservation list on every edit iteration.
- Declare the ratio in the native field and prompt. Use `background` or another native field for transparency when exposed; do not rely on descriptive wording alone.
- End with one medium lock and short conflicting-medium exclusions. Avoid one flowing 400-word prompt, repeated all-caps enforcement, and camera specifications presented as physical guarantees.
- WeShop default remains `quality: medium`, `imageSize: 2K`, one result unless the user requests a different tier or count.
