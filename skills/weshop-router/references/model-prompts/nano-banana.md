# Nano Banana prompt guide

- Best fit in this package: explicit fast draft divergence (`nano2`) or internal convergence/review (`nano`), especially iterative edits and multi-reference variants without critical copy.
- Use descriptive natural sentences: medium/style, named subject, setting, action, composition/camera, lighting, then a final medium lock.
- Keep the prompt focused. Prefer a clean base plus targeted iterations over a long specification.
- Name every reference by index and role; name multiple subjects rather than relying only on left/right position.
- Repeat invariants on each edit: identity, pose, layout, camera, lighting, background, and protected objects.
- Use descriptive colors rather than expecting hex values or exact font names to render literally.
- Avoid long or exact typography, repeated all-caps constraints, anonymous references, and large negative-keyword lists. Route copy-critical finals to GPT Image 2.
- Only use fields currently exposed by `nano-banana-edit`; do not copy MiniMax Hub aliases or reference-count claims into requests.
