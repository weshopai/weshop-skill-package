# Veo 3.1 prompt guide

- Best fit: source-image cinematic video where rich native audio, dialogue, precise SFX/ambience, and 16:9 or 9:16 delivery matter more than speed or ratio flexibility.
- Use a coherent five-part prompt: cinematography/composition, specific subject, concrete action, context, style/ambience. Add labeled dialogue, SFX, ambient noise, and music.
- Quote exact dialogue, state the speaker's action and tone before the line, and keep each clip within one inspectable action arc.
- Current WeShop Agent is `veo-ai`, requires one input image, uses `Veo_3_1|Veo_3_1_Fast`, `16:9|9:16`, and `4s|6s|8s`. It does not expose the reviewed MiniMax ingredients, first/last-frame, extension, add/remove, resolution, or explicit audio fields; do not claim or submit them.
- Critical text remains a deterministic overlay. Avoid vague subjects, unsupported ratios/durations, and multi-shot timestamp structures that the current WeShop schema cannot express safely.
