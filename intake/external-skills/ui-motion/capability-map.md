| External behavior | Inputs and constraints | WeShop decision | Evidence |
| --- | --- | --- | --- |
| A UI-state motion demo using authentic supplied interface assets and deterministic exact-copy finishing. | Authorized assets/facts, explicit preservation constraints, and observable acceptance | Split candidate: `make-ui-motion`; use only a current verified route if promoted | Source entrypoint review and current Router contract |

## Deterministic operations retained locally

- Source/fact ledgers, accepted-output bindings, exact-copy finishing, frame inspection, and final acceptance reporting.

## Unsupported parity

- Source application UI/state, plugins, Canvas/graph APIs, hidden model controls, automatic fallbacks, autonomous publication, and unverified standalone audio.

- Split candidate: `make-ui-motion`.
- Adjacent current ownership: `make-kinetic-typography`, `brand-promo-video-generator`, `generate-video`.
