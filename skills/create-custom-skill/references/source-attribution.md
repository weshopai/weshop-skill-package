# Source attribution

This Skill was informed by the user-supplied MiniMax Design `skill-creator` export reviewed on 2026-08-21. The reference contributed the useful product ideas of authoring from a new brief, capturing a completed conversation, revising an existing Skill, trigger testing, workflow walkthrough, isolated user ownership, and iteration from observed use.

The WeShop adaptation does not copy MiniMax Hub runtime assumptions. It removes `~/.hub` and `~/Movies/Hub` paths, Skill Plaza installation, `hub_reload_skills`, mandatory `SKILL.cn.md`/`meta.yaml`, Hub tag enums, Hilo token instructions, and the fixed media-production template. It replaces them with package-native `SKILL.md` structure, user-custom intake, one unified local creation/check/install lifecycle, current-harness target discovery, explicit installation approval, Router relationship scoring, and official WeShop execution boundaries. Independent review is deferred until the user requests official upload or package contribution.

Reviewed source fingerprints are recorded in `intake/external-skills/minimax-skill-creator/` in the package repository.
