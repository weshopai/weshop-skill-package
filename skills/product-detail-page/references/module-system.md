# Module system

Choose modules from buyer questions and available evidence. Do not use every module by default.

| Module | Buyer question | Suitable evidence | Typical visual |
| --- | --- | --- | --- |
| hero | Is this for me? | Product identity and primary verified value | Product-led scene with one headline |
| feature | What is the main benefit? | Verified feature and use outcome | Product plus one visible mechanism |
| detail | Why should I believe it? | Material, construction, control, finish | Macro crop or annotated detail |
| scenario | Where or when is it used? | Plausible, non-deceptive use context | Product-in-use scene |
| steps | How do I use it? | Verified sequence | Numbered deterministic panels |
| specs | Will it fit or work? | Supplied dimensions, compatibility, contents | Diagram or structured table |
| comparison | Which variant should I choose? | Verified variant facts | Native or deterministic comparison table |
| trust | What reduces purchase risk? | Supplied certification, warranty, care, test evidence | Evidence-led card; never invented badges |
| closing | What should I remember? | Product identity and approved message | Restrained recap, not a second unsupported hero |

## Suggested sequences

### Marketplace long detail

`hero → primary value → detail evidence → scenario → secondary value → steps/specs → purchase-risk reducer → closing`

### Amazon-style modular content

`brand/product banner → product use/feature → multiple details → specs or comparison → optional brand story`

Keep copy in platform-native fields where available. The module images should still work after responsive stacking.

### Shopify/DTC media set

`clean product → alternate angle → detail → scale/use → scenario → instructions/specification`

The storefront theme owns final page assembly; deliver independent, consistently proportioned media.

## Visual rhythm

Alternate scale and density deliberately:

- wide environment or hero;
- medium product demonstration;
- close material/detail crop;
- structured information module;
- calm closing or trust section.

Do not repeat the same centered product, gradient background, floating icon cluster, or oversized headline in every module.

## Facts and copy

Map every claim to a fact ID. Prefer specific, helpful language over unsupported superlatives. Keep one message per module. Longer explanations belong in native text fields or deterministic text blocks, not inside generated imagery.
